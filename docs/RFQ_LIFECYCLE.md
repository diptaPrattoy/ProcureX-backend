# RFQ Lifecycle

`DRAFT → OPEN → EVALUATING → AWARDED`, with cancellation paths where business rules permit.

- Only the owning buyer can manage an RFQ.
- Only drafts are editable.
- Publishing requires a valid active category, items, future deadline, and verified buyer email.
- Suppliers discover only open, non-deleted, non-expired RFQs.
- Soft deletion is available only for safe RFQ states.
- Published/evaluating RFQs are protected from silent commercial edits.
