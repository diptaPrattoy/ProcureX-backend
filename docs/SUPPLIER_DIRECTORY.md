# Supplier Directory and Verification

Public supplier discovery exposes only active, non-deleted, `VERIFIED` suppliers and intentionally omits sensitive business identifiers/contact fields.

Before verification, a supplier must have:

- active account;
- verified email;
- business registration number;
- at least one active procurement category.

A rejection requires an admin note. Changing verified legal identity fields returns the supplier to `PENDING` so the new identity is reviewed again.
