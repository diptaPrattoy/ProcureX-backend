# Quotation Lifecycle

- Only active, email-verified, admin-verified suppliers may quote.
- Supplier must belong to the RFQ category.
- One supplier has one quotation record per RFQ.
- Currency must match the RFQ.
- RFQ items are priced exactly once; requested quantities are not supplier-editable.
- Line totals/subtotal/tax/total are server-calculated.
- Supplier may update/withdraw only during the allowed RFQ window.
- Buyer evaluation locks active quotations into review state before award.
